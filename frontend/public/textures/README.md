# Globe texture attribution

`earth-topography.jpg` is a local copy of `earth_atmos_2048.jpg` from the official Three.js examples repository:

- Source: https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg
- Repository license: MIT — https://github.com/mrdoob/three.js/blob/dev/LICENSE
- Downloaded as a 2048 × 1024 equirectangular texture; served locally so the globe does not depend on a runtime image host.

The image has been bundled for this demonstration. If the app is redistributed independently, verify any separate third-party image attribution requirements alongside the Three.js MIT notice.
